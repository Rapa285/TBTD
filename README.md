# Terminal Blitz Tower Defense
[![Watch the video](https://img.youtube.com/vi/e6wwSH5Wz50/0.jpg)](https://www.youtube.com/watch?v=e6wwSH5Wz50)

## Description

Termina Blitz is an intense **War Roguelike Tower Defense** filled with unique unit management mechanics, set amidst the chaos of World War III (WW3).

The world is in ruins due to a never-ending global conflict. In the shadow of this war, seven experimental supersoldiers 
have escaped from a top-secret military facility. Seeking peace, they build a modest, protected home to live out the rest of their lives in peace. 
However, their retirement is shattered when a ruthless army of clone soldiers from a neighboring country approaches their home. 
Mistaking their ordinary home for a crucial secret enemy base, the clone army launches a merciless, full-scale attack.

You command these seven elite veterans—who act as your "towers"—to defend their home. 
Tactics and timing are key: each soldier has limited ammunition and must strategically retreat indoors to reload, 
leaving your defenses temporarily vulnerable. As you successfully survive waves of enemies, you'll earn a variety of 
powerful roguelike-style upgrades to modify their combat abilities. Your objective is simple: control your troops' rhythm, 
hold the line, and survive the endless onslaught of clone troopers as long as possible.

## Playing the Game

If you only want to play Terminal Blitz Tower Defense, download the latest build from the [Releases page](https://github.com/Rapa285/TBTD/releases) instead of cloning the repository.

1. Download the latest release archive for your platform.
2. Extract the archive.
3. Run the included executable.
   
## Development
### Installing
For development, clone the repository and open it in Unity.

1. Clone the repo 
   ```sh
   git clone https://github.com/Rapa285/TBTD
   ```
2. Open the project in Unity `6000.4.2f1` or a compatible Unity 6 editor.

### Running in Unity

To playtest from the editor, open the bootstrap scene:

```text
Assets/Scenes/Final Scenes/Bootstrap.unity
```

Then press Play in the Unity Editor.
